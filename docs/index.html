Règles de génération Légal dur : indispo, chevauchement, 11 h de repos, pause ≤ 5 h, plafonds jour/semaine, contrat tant qu’un collègue est sous-heures. Choix : le plus sous-heures, à ratio égal on finit la journée déjà commencée, puis le niveau le plus proche. On ne vole pas l’unique ouvreur d’un poste plus tôt. Les coupures se comptent par semaine (warning, pas un refus). Un trou après un passage glouton relance d’autres départs déterministes. La bande 16 h–18 h sur le Gantt est la pause midi–soir, pas un trou de couverture.
